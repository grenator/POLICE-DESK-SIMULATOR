# POLICE-DESK-SIMULATOR
Become a police officer reviewing cases, evidence etc. write reports &amp; open investigations. 

This is my first Godot game created without *any* tutorials, everything is 100% made by me *(grenator/Conor)*
Anyone is welcome to use assets from here, It's more so just a show of my skills in practice after 3 months using 
The Godot game engine.

There will be quite a few more things added, version 1 includes:
- 5 different cases to investigate
- Review reports & evidence reports
- Write a small review
- Close the case

Planning to add a XP progression system so you can climb through the ranks of being a detective investigator.
